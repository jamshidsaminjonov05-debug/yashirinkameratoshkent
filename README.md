# YASHIRIN CAMERA

Toshkentdagi yashirin mini kameralar, GPS proslushka, diktofonlar va mikro naushniklar
onlayn do'koni. 2013 yildan beri optom va chakana savdo.

Next.js 16 (App Router) + React 19 + Tailwind CSS v4 + GSAP + Motion. Sayt ikki tilli: ru va uz.

```
npm install
npm run dev        # $PORT (standart 8443) da dev server
npm run build      # ishlab chiqarish build
npm start          # build qilingan saytni ishga tushirish
```
